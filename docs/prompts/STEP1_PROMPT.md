### 2. [A1] 「星盘检字法」索书框双模升级
- 不改动原有隐藏数字口令监听的前提下：
  - **实时馆内过滤**：输入普通字符或 `#tag` 时，下方卡片实时过滤高亮、其余压暗；按 `Shift + Enter`（或无馆内匹配且非隐藏口令时按 `Enter`）直接调用所选外网搜索引擎。
  - **前缀命令面板**：输入以 `/` 或 `>` 开头时，在搜索框正下方展开克制的「古籍批注式命令条」，支持上下键或点击执行：
    - `/theme`：切换观星台（深色）/ 日晷（浅色）
    - `/random`：触发「今日开卷」随机抽卡
    - `/export`：一键导出全馆 JSON 与借阅账本备份
    - `/clear-dust`：重置蒙尘状态

### 3. [A2] 「索书号直达」全键盘盲打跳转
- 为当前视图下的卡片按顺序分配两位索书号（`01`、`02` … `36`），显示在右下角 `№ 01`。
- 焦点**不在**任何 `input / textarea` 内时监听全局数字键：450ms 内连按两位数字（如 `0` 再 `1`），屏幕右上角浮现精致的黄铜线框印章 Toast `[ 正在调阅 № 01 · DeepSeek ]`，并在新标签页打开对应 URL（同时记入借阅热度）。

### 4. [A4] 「阅览室借阅热度」与「古籍蒙尘」
- 建立 `MYNAV_LEDGER_V2` 存储模块：每次点击卡片或通过索书号打开网站，静默记录 `count + 1` 与 `lastVisited = Date.now()`。
- **动态「🔥 常驻案头」**：点击「🔥 常驻案头」筛选时，除手动标记的卡片外，自动合并近 7 天点击最高的 Top 6，并在卡片底部显示微缩借阅戳（如 `调阅 12 次 · 末次 10.18`）。
- **古籍蒙尘**：距今超过 60 天未点击的卡片加 `.card--dusty`（整体透明度降至 `0.78`，右上角浮现极淡 `[ 尘封 ]` 印记，Hover 恢复清晰）。提供控制台或数据层的模拟开关方便测试。

### 5. [A8] 「今日开卷 · 随机寻星」（快捷键 `R`）
- 点击顶栏 `✦ 随机开卷` 或非输入态按 `R`：背景星盘 / 日晷圆环快速旋转 180deg，随后从全馆非置顶的深层卡片中随机抽 1 张，以「今日推荐藏书票」弹窗（双线古籍边框、大号编号、完整评注、`[ 立即调阅 ↵ ]` 按钮）居中展示。
