# mynav 功能提案汇总 · EX LIBRIS

> 整理自 2026-10-19 的四批讨论，保留全部细节。
> 共 22 个 idea：馆内效率与策展 8 个（A1–A8）、待编目匣 1 个（B）、拓展型模块 6 个（C1–C6）、颠覆性拓展 7 个（D1–D7）。

---

## 0. 设计总原则

- `mynav` 已立住 **EX LIBRIS（古典藏书馆 / 观星台 / 日晷）** 骨架。
- **忌讳**：塞现代网页常见的「天气插件、番茄钟、花哨仪表盘」——瞬间破功，把古籍仪器感拉回普通工具站。
- **理想形态**：外表像古籍馆藏与天文仪器细节，内里是极客级高效工作流与无缝后端。
- **两层演进**：
  - 第一层（A、B）：在「书签夹」物种内部做微创新——怎么更好地存网址、找网址。四个维度：馆藏策展、硬核键盘流、无头数据底座、沉浸仪式感。
  - 第二层（C）：拓展性（Expansive）——打破「导航站 = 链接中转站（看一眼就走）」的宿命，把 `mynav` 从静态「藏书目录」升维成每天驻留的「**个人数字控制台（Personal OS / 观星主控室）**」。外壳保持古典仪器与古籍不变，往里注入能跨平台联动、能执行操作、能处理信息的重型模块。
  - 第三层（D）：撕掉「导航站」概念——新标签页本身就是有算力、有记忆、能交互、能分身的「数字领地」。

## A. 馆内效率与策展（第一批）

### A1. 「星盘检字法」：索书框双模升级（外网搜索 + 馆内命令面板合一）
- **现状**：搜索框只负责调用 Google 搜全网。
- **方案**：加前缀指令系统，不做额外弹窗，在当前「索书条」里无缝切换。
- **默认输入**：模糊匹配当前 36 卷馆藏，支持拼音首字母或标签（如 `#ai`）；匹配卡片在下方实时高亮，其余压暗；无匹配或按 `Shift + Enter` 直接跳 Google 搜索。
- **指令前缀 `/` 或 `>`**：
  - `/theme` 切换观星台 / 日晷模式
  - `/random` 随机抽一卷
  - `/sync` 触发云端书签同步
  - `/export` 导出全馆 JSON 备份
- **隐藏数字口令**：原有的继续在底层静默监听；可扩展多组「馆藏密令」通往不同私人服务。

### A2. 「索书号直达」：全键盘盲打跳转（Chord Shortcuts）
- **现状**：卡片右下角 `№ 01`、`№ 02` 编号只是装饰。
- **方案**：变成真正的物理索书号。页面非输入状态下，快速连按两位数字（如 `0` `1`）→ 右上角浮现黄铜印章提示 `正在调阅 № 01 · DeepSeek...` → 新标签页打开该站点。
- 前 9 个高频站点（常驻案头）不碰鼠标，进站半秒内即可盲打打开。

### A3. 「藏书票背光 / 批注面」：卡片翻转或侧滑抽屉（Marginalia）
- **痛点**：正面只放一句简介；AI 平台、开发工坊、自建服务等常有使用备忘、常用子路由、API 控制台直达链接无处放。
- **交互**：点击卡片右下角 `藏书票 № 01`（不是卡片主体）→ 3D 翻面（或展开底部暗格）→ 露出背面「馆主批注（Ex Libris Notes）」。
- **内容**：背面用手写体 / 等宽字体排印私人评价、常用快捷子链接（例：DeepSeek 卡背面挂 `API Keys`、`Usage 账单`、`Docs` 三个微缩直达锚点）。
- 正面保持极简，背面承载高密度实用信息。

### A4. 「阅览室借阅热度」：自动演化的「🔥 常驻案头」与陈旧蒙尘
- **目标**：`🔥 常驻案头` 从纯手动勾选变成「活」的。
- **借阅计数（Access Ledger）**：本地 `localStorage`（或同步云端 KV）静默记录每张卡点击频次与最后访问时间。
- **动态晋升**：近 7 天点击最高的 Top 6 自动晋升到 `🔥 常驻案头`；卡片背面印古籍借阅卡式日期戳（如 `最后调阅：2026.10.18`）。
- **古籍蒙尘机制（Dusting Effect）**：超过 60 天未点击的冷门馆藏，边框与文字透明度微降 15%，角标浮现极淡蜘蛛网 / 尘封符号，提醒清理或重新审视。

### A5. 「星轨联通探针」：自建服务与节点的微光状态灯
- **痛点**：收录的自建博客、个人项目、私人服务面板出现死链影响体验。
- **形态**：卡片图标旁或右上角方框处一枚 2px 星点状态灯。
- **实现**：Cloudflare Workers 写轻量 `/api/ping` 接口（或纯前端 `fetch no-cors` / `Image` 探测），进站时静默巡检核心站点连通性与延迟。
- **视觉**：不用红绿灯。深色模式在线 = 微弱呼吸的恒星暖白光；离线 = 熄灭的暗红残星；Hover 以天文学单位显示响应耗时（如 `Δt 42ms`）。

### A6. 「Notion 典藏馆同步」：Notion 数据库作无头后台
- **痛点**：加新网站要改代码或进后台填表单，繁琐。
- **方案**：Notion Database 当云端藏书目录，字段：`Title`、`URL`、`Category`、`Description`、`Rank`、`Tags`、`Notes`。
- 手机 / 电脑看到好网站，用 Notion Web Clipper 一键剪藏进库。
- Cloudflare Worker 定时拉取（或缓存）Notion API 数据渲染到 `mynav`；Notion 里改一行字、打个星标，刷新即更新成新藏书卡——「多端随手收录，前端古典展陈」。

### A7. 「真·天文日晷与实时星图」：背景与真实物理时间挂钩
- **浅色（日晷模式）**：读取系统时间（如 10:00 vs 16:30），动态计算太阳高度角与方位角，背景大尺度日影斜线与卡片微弱投影方向随真实时间缓慢偏转。
- **深色（观星台模式）**：左栏底部经纬仪读数实时显示当前恒星时（Sidereal Time）；固定流星雨日期（八月英仙座、十二月双子座等）背景高概率划过长尾流星。

### A8. 「今日开卷 · 随机寻星」：盲盒式灵感抽取
- **痛点**：收藏 50 个好站，平时只点前 5 个，其余吃灰。
- **形态**：左栏书脊底部或顶栏加 `✦ 随机开卷（Serendipity）` 按钮，快捷键 `R`。
- **交互**：背景星盘快速旋转定格，从全馆**非置顶的深层馆藏**随机抽一张，以「今日推荐藏书票」形式居中放大展示。

## B. 「待编目匣 / 暗星带」：备用网站的二级隔离缓存区（第二批）

### 痛点
- 「食之无味、弃之可惜，混在主列表里又严重干扰高频检索」。
- 现有 `全部藏目`、`⭐ 私人典藏`、`🔥 常驻案头` 都是「已确认价值并正式入馆」的藏品。
- 若把「看着很厉害、以后某项目可能用到、但现在完全不点」的网站塞进正式分类（如 `AI 思考与生成`、`开发与代码工坊`），不出两个月主画布会被几十个低频卡片稀释成杂物间。
- 定位：包装成极具仪式感的二级隔离缓存区，从概念命名、空间位置、卡片形态、生命周期流转四个维度打磨。

### B1. 概念命名（不叫「稍后阅读」）
- **藏书馆流派**：「待编目匣 · Uncatalogued Box」或「善本暂存库 · Quarantine Vault」——新收古籍未经馆长精读、写批注、贴正式藏书票前不能上主书架，只能牛皮纸封条绑好放在案头侧边木匣。
- **观星台流派**：「奥尔特云 · Oort Cloud」或「未定轨暗星 · Uncharted」——被望远镜一闪捕获、尚未测算固定轨道、未来可能成为亮星的边缘星体。

### B2. 空间摆位：不占主分类书脊，做「侧边暗格」
- 原则：**不出现在默认展开的『全部藏目』流里**。
- **方案 A · 左栏书脊底部「独立档案抽屉」**：分类最下方用虚线与正式分类隔开，单独入口 `[ ⌘ 待编目匣 · 12 ]`；平时完全隐藏，点击或按 `U` 时右侧画布像拉开底层铁皮文件柜，专门平铺这批网站。
- **方案 B · 右栏索书条旁「夹页便签袋」**：在 `⭐ 私人典藏`、`🔥 常驻案头` 旁挂半透明虚线框标签 `⏳ 候选封存`；点击从右侧滑出宽 380px 的半透明羊皮纸 / 星图侧边抽屉，不离开主页面即可翻阅。
- **待决**：选 A 还是 B。

### B3. 视觉降权：区分「正式馆藏」与「候补观察」
- 做成「未拆封 / 草稿」质感，与正式 `藏书票 № 01` 拉开代差。
- **无正式编号**：只给临时铅笔印记 `TMP-04` 或 `[待定轨]`；右下角不贴黄铜藏书票，只盖半透明线框章 `[ 留卷待查 ]`。
- **虚线框 + 高密度条状**：1px 刻度虚线（Dashed Border）；复用紧凑型「窄幅索书签」排版，一屏二三十个，扫视极快。
- **专属字段「收录动机（Why Saved）」**（最核心）：不写官方简介，用斜体突出一句存它时的直觉备注，如 *「以后做地图可视化切瓦片可能用得上」*、*「免费额度高的备选 TTS 接口」*——防止半年后忘记为什么存（尤其名字抽象的开源工具或小众 API）。

### B4. 动态流转：转正与自然淘汰（防止变成死链接坟场）
1. **全局搜索照常穿透**：主界面看不见，但在搜索框搜关键词（如 `图表`、`API`）时，结果底部自动附一栏「**来自待编目匣的潜在匹配**」。
2. **一键加冕（入馆转正）**：点卡片上 `[ ✦ 授予藏书票 ]`，褪去虚线外框，自动分配正式 `№` 编号，归入对应主分类书脊。
3. **半衰期提醒 / 随机盲盒**：躺超过 90 天一次没点开 → 角落浮现微弱沙漏印记；或「随机开卷」时优先抽出并询问：*「这件藏品已封存三月，要正式入馆，还是直接销毁？」*

## C. 拓展型模块：从藏书目录到观星主控室（第三批）

### C1. 「活字秘卷匣 · Codex Snippets」：从存链接到存算力与弹药
- **背景**：头号主力分类 `AI 思考与生成`（DeepSeek、Muse、ChatGPT、Hark、Gemini 等）与 `开发与代码工坊`；跳过去时常要带一段 System Prompt、Linux 部署命令、正则 / 配置模板。
- **形态**：独立分卷，存高频文本资产——常用 Prompt 模版、服务器一键脚本、API Base URL 备忘、跨设备临时文本。
- **交互（带弹跳转）**：点击某张秘卷 → 自动复制到剪贴板 → 弹出微缩星轨菜单 `[ 携卷前往：DeepSeek | ChatGPT | Gemini ]` → 点哪个就打开对应 AI 网页。「粮草与兵刃合一」。

### C2. 「观星简报台 · Daily Ephemeris」：从点出去看到在馆内批阅
- **痛点**：普通导航站要挨个点开 10 个标签页看有没有更新。
- **形态**：Cloudflare Workers 或定时任务后台静默抓取信源——GitHub Trending、特定大佬博客 RSS、Linux.do / V2EX / HackerNews 精选、某学科前沿动态。
- **视觉**：不做现代信息流，排成夹在导航站里的《观星台晨报》（古典双栏铅字报纸版式）。
- **用法**：每早切到「晨报」视图，3 分钟扫今天全网最有价值的 15 条；看到好文好项目点旁边 `[ ✦ 收入待编目匣 ]`（接入 B）。

### C3. 「星群连珠 · Constellation Workflow」与聚合投射：多站并发调度
1. **工作流星群（Workspace Launcher）**：
   - 进入某种状态（写代码 / 搞基建、查资料 / 写东西、日常摸鱼）时打开的总是固定 3–4 个网站。
   - 把任意几张卡片用线条连起来定义为「星座预设」：如 `[科研星群]` = 特定数据库 + AI 助手 + 笔记库；`[运维星群]` = Cloudflare + GitHub + 探针面板。点顶部星座图标，工作台瞬间就位。
2. **「星际广播」多引擎 / 多 AI 并发投射（Multi-Cast）**：
   - 索书框输入问题后切到 `[ ✦ 群星会诊 ]` 模式：回车同时唤起 2–3 个搜索引擎（如 Google + GitHub + Perplexity），或通过 URL Query 参数把同一问题喂给多个支持 URL 传参的 AI 搜索页，一键多路比对。

### C4. 「星轨遥测与机关台」：私人基建遥控器（API & Webhook 控制台）
- **背景**：自有服务器、域名和各类云端配置；传统导航站只能给个跳后台的链接。
- **嵌入式微型仪表（Telemetry Cards）**：卡片网格里混入一两张「仪器卡」，不跳转，通过 API 实时显示：某台 VPS 当前负载 / 剩余流量、OpenRouter / DeepSeek API 账户剩余余额、某域名到期倒计时。
- **「黄铜扳手」Webhook 触发器**：卡片上挂物理感微缩开关，点一下直接发请求——触发 Cloudflare Pages 重新构建、触发云端数据库自动备份、远程唤醒某台服务。

### C5. 「飞鸽传书 · 跨端入馆通道」：全网随处捕获
- **痛点**：只能打开导航站时才能加东西，输入链路断裂。
- **浏览器「加盖藏书票」Bookmarklet 或极简插件**：在任意网页（如 GitHub 神级仓库）点书签栏 `[ ✦ 盖章入馆 ]` → 当前页浮现半透明 EX LIBRIS 印章弹窗 → 自动抓取标题、域名、Meta 简介 → 可调用轻量 AI 接口浓缩成 20 字古风 / 克制评语并自动选分类 → 回车写入导航站数据库。
- **Telegram Bot / 快捷指令投递**：手机看到好链接转发给私人 Bot，附一句语音或文字备注，自动归档进「待编目匣」（接入 B），开电脑时已在案头排好队。

### C6. 「穹顶星图 · Knowledge Graph」：从列表检索到知识星图
- **痛点**：现有分类（AI、开发、知识、效率）是非黑即白的树状文件夹，一个网站只能属一个分类；实际很多工具跨界（既 `#ai` 又 `#代码` 又 `#常驻`）。
- **形态**：右上角眉批导航栏加视图切换 `[ 书本目录 / 穹顶星图 ]`。
- **星图视图**：收起矩形卡片，画布变成类 Obsidian 的 2D 引力关系星图——分类是恒星，36 个网站是围绕的行星，相同 `#tag` 的跨分类网站之间自动拉起细微黄金星座连线；直观看到工具版图重心，拖拽一颗星会产生真实物理连线牵引。

## D. 颠覆性拓展：新标签页即数字领地（第四批）

> 再推一层，直接撕掉「导航站」概念：为什么浏览器新标签页（New Tab）只能用来跳去别人的网站，而不能本身就是一个**有算力、有记忆、能交互、能分身的「数字领地」**？保持 EX LIBRIS 皮囊，往外炸开 7 个带科幻 / 黑客浪漫主义的方向。

### D1. 「守馆人 AI · 司天监（The Librarian）」：索书框变私人 Agent 终端
- **痛点**：搜索框写着 `用 Google 搜索全网`，下方第一栏是 DeepSeek、Muse、ChatGPT、Gemini，却还得先点卡片、等加载、再输入。
- **懂全馆藏书的 RAG 顾问**（前缀 `?`）：记不清该用哪个工具时直接输入自然语言，如 `? 帮我挑个适合处理地质图层或切图的工具`、`? 我之前存过哪个免费查 IP 泄漏的站`；搜索框下方以**古籍批注条**形式流式输出回答，并把馆内（含「待编目匣」）对应卡片抽出递给你。
- **就地处决轻任务（In-Place Execution）**（前缀 `!`）：接入现有 DeepSeek API，如 `! 帮我写个把 443 端口转发到 8080 的 iptables 命令`、`! 翻译这段摘要`；不跳转任何外部网页，在原地「羊皮纸浮层」吐出结果，按回车直接复制走人。理念：30 秒内能解决的轻问题，不配多开一个 Tab。

### D2. 「多重人格面具 · 馆长分身」（Persona / 访客与私密双生空间）
- **背景**：右上角现有 `登录` 按钮；「未登录 vs 已登录」太无聊，做成同一座图书馆的平行结界。
- **表世界 · 会客室**：别人访问你的域名，看到一套体面、克制、极具审美的公开藏书馆（主流 AI、开源工坊、公开博客）；可生成精美的 **「今日馆藏名片」** 分享给朋友抄作业。
- **里世界 · 密室卷宗**：输入特定搜索框暗语（或触发隐藏机关）→ 背景星盘逆时针旋转 180° → 进入「**暗月模式**」→ 公开卡片翻面或隐去，切换为私人节点面板、自建账密库入口、私有云盘、备考或私密创作专属资料库。
- **考场 / 沉浸结界（Focus Lock）**：开启后偏娱乐、社交（如 `联络与社交` 分类）的卡片全部贴上古籍「封条（Sealed）」不可点击，只留专业工具与学术检索，配合日晷倒计时强行锁定心流。

### D3. 「炼金实验台 · 微型沙盒」：黄铜工具尺（Brass Instruments）
- **痛点**：开发 / 写作时常用琐碎在线小工具（看当前 IP 与分流节点状态、Base64/URL 编解码、JSON 格式化、时间戳转换、正则测试、配色吸管），专门去开满是广告的第三方站极打断思路。
- **形态**：侧边或底部可拉出的「黄铜工具尺」，极简古典几何线条 UI，纯前端 JS 本地实现、零延迟的高频瑞士军刀：
  - **星象罗盘（网络探针）**：进站自动静默显示当前国内外出口 IP、DNS 状态与延迟；瞥一眼左下角罗盘就知道代理通没通，不用开测速站。
  - **译码转盘**：拖入乱码、JSON、JWT 或 Base64，原地解码清洗。
  - 其余：时间戳转换、正则测试、配色吸管等。

### D4. 「星轨编年史 · 数字足迹热力图」（Time-Lapse & Almanac）
- **立意**：日晷与观星台的核心都是「时间」，但现在网站没有时间记忆。
- **观星年历（Almanac Grid）**：馆藏底部或侧栏一条类 GitHub 贡献图的「古典星历表」，不用绿方块，而用**月相盈亏（朔月 → 上弦 → 满月）或星点亮度**记录每天的数字活跃轨迹（今天调阅多少次 AI、开了几次代码工坊、新收录几卷书）。
- **时光倒流滑块**：拖动底部日晷时间轴，看半年前、三个月前最常驻案头的工具是什么，哪些曾天天用的网站已熄灭成暗星——形成专属的**个人技术栈与兴趣演化史**。

### D5. 「网页琥珀 · 离线快照与防失联保险箱」（Dead-Link Amber）
- **痛点**：半年前收藏的神级教程、惊艳独立小站，今天变成 `404 Not Found` 或域名过期被抢注成赌博站。
- **形态**：给「⭐ 私人典藏」卡片加「**琥珀封存（Amber Archive）**」能力。
- **机制**：标记为最高级别私人典藏时，后台自动调用 Wayback Machine（Internet Archive）归档接口，或用 Cloudflare Worker 抓取页面纯文本 / Markdown 摘要存进云端数据库。
- **失联时**：配合 A5 星轨联通探针检测到 404 → 卡片 `[ ↗ ]` 箭头自动变成琥珀色 `[ 📜 调阅拓片 ]` → 别人打不开的死链，你照样能看馆里留存的历史拓片。

### D6. 「白噪音天文台 · 环境声场发生器」（Ambient Soundscape）
- **背景**：导航站常作为浏览器第一个固定标签页（Pinned Tab）一直挂着。
- **入口**：右上角眉批处一枚克制的音叉图标 `[ 𝄞 听风 / 寂静 ]`。
- **实现**：浏览器原生 **Web Audio API** 纯代码合成，不加载几十兆音频文件。
  - **观星台模式**：极低频深空电磁波底噪 + 偶尔微弱星际脉冲声 + 远处机械赤道仪齿轮极缓慢的滴答声。
  - **日晷阅览室模式**：翻动厚重古籍纸张的沙沙声 + 窗外极淡的风声与钟摆声。
- 戴耳机写代码或看书时，化身无广告、零内存占用的沉浸式自习室。

### D7. 「馆际互借 · 联邦星图（Federated Webring）」
- **场景**：弟弟、朋友或同好也用这套模板（或有自己的个人主页 / 导航站）。
- **形态**：观星台边缘留一个「**邻近星系 · 望远镜（Telescope）**」。
- **协议**：简单 JSON 订阅（类 RSS），每个导航站自动暴露 `/public-collection.json`。
- **交互**：转动右下角「寻星镜」，不离开自己的导航站即可切到朋友的公开藏书架，看他最近发现的新工具；喜欢的一键 `[ ✦ 拓印入馆 ]` 抄进自己收藏。

### 第四批定位总结
`mynav` 彻底脱离「网址大全」：AI 快捷终端（守馆人）、网络与日常瑞士军刀（炼金实验台 / 出口 IP 罗盘）、表里双生密室（暗月模式）、防 404 网页拓片库（琥珀封存）、沉浸白噪音自习室。原文提议：挑最契合日常习惯的几个拧成一股绳，定下 **`mynav 2.0` 终极蓝图**。
