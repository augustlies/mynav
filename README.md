# mynav · 个人数字收藏馆

一个本地优先、支持可选云端同步的个人网址导航站：把常用网站按专栏分类收藏，做成一本可以搜索、可以随手改的私人网址簿。

## 功能

- **分类收藏**：网址按专栏（AI、开发、学习、效率等）分组，卡片展示名称、简介和标签
- **搜索**：输入关键词实时过滤馆藏，也可以切换搜索引擎直接搜全网，或用 `?` / `!` 召唤司天监助手
- **两种视图**：书本网格视图与穹顶引力星图，一键切换
- **深浅主题**：浅色 / 深色两套主题，可跟随系统、自然时序或手动切换，并支持尼尔纸张底色与粒子动效
- **直接改，不用写代码**：右键卡片（手机上长按）即可新增、编辑、移动、隐藏、删除；改动默认保存在浏览器本地
- **备份与恢复**：一键导出 `data.js` 或完整 JSON 备份，也可导入恢复；把导出的 `data.js` 替换回仓库即可永久生效
- **多端云同步（可选）**：注册账号后基于三方合并协议与 Cloudflare KV 跨设备同步收藏、访问账本（`MYNAV_LEDGER_V2` 中的点击/日历/批注/秘卷/星图）、排序、主题、偏好与卡片编辑（本地 AI 密钥与网页琥珀快照仅留本机，不上传）
- **Notion 全局改卡片**：Notion 数据库管卡片内容，服务端缓存到 KV，浏览器首屏用本地缓存、空闲时更新；改完发一次刷新请求即可全设备生效，详见 `NOTION_CARDS.md`
- **常用自动靠前**：打开次数多的站点会自动排到案头区域
- **快捷键**：`/` 快速搜索、`R` 随机打开一个收藏、输入两位编号直达对应卡片、`?` 查看全部快捷键

## 使用

不需要构建，任选一种方式打开：

```bash
# 方式一：直接用浏览器打开 index.html

# 方式二：起一个本地静态服务
python3 -m http.server 8080
```

部署就是静态托管：把仓库推到 GitHub 后，用 Cloudflare Pages 连接仓库即可（框架选 None、构建命令留空、输出目录 `/`）。

修改数据、脚本或静态资源后，可执行校验与测试：

```bash
node validate.js
node scripts/build-sw.js          # 刷新 sw.js 离线预缓存清单
node scripts/build-sw.js --check  # 校验 sw.js 与 404.html 资源版本一致
node --test tests/*.test.cjs
```

## 技术

原生 HTML / CSS / JavaScript，无框架、无打包步骤。站点数据在 `data.js`，页面逻辑在 `app.js` 和 `js/` 目录下，云同步与 Notion 卡片接口在 `functions/`（Cloudflare Pages Functions）。
