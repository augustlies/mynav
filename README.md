# mynav · 个人数字收藏馆

一个纯静态的个人网址导航站：把常用网站按专栏分类收藏，做成一本可以搜索、可以随手改的私人网址簿。

## 功能

- **分类收藏**：网址按专栏（AI、开发、学习、效率等）分组，卡片展示名称、简介和标签
- **搜索**：输入关键词实时过滤馆藏，也可以切换搜索引擎直接搜全网
- **两种视图**：普通网格视图和 3D 书架视图，一键切换
- **深浅主题**：浅色 / 深色两套主题，可跟随系统或手动切换
- **直接改，不用写代码**：右键卡片（手机上长按）即可新增、编辑、移动、隐藏、删除；改动保存在浏览器本地
- **备份与恢复**：一键导出 `data.js` 或完整 JSON 备份，也可导入恢复；把导出的 `data.js` 替换回仓库即可永久生效
- **常用自动靠前**：打开次数多的站点会自动排到案头区域（统计只存在本地浏览器，不上传）
- **快捷键**：`/` 快速搜索、`R` 随机打开一个收藏、输入两位编号直达对应卡片、`?` 查看全部快捷键
- **Notion 管理内容**：馆藏数据维护在 Notion 里，运行 `node notion-sync.js` 即可同步生成 `data.js`

## 使用

不需要构建，任选一种方式打开：

```bash
# 方式一：直接用浏览器打开 index.html

# 方式二：起一个本地静态服务
python -m http.server 8080
```

部署就是静态托管：把仓库推到 GitHub 后，用 Cloudflare Pages 连接仓库即可（框架选 None、构建命令留空、输出目录 `/`）。

修改数据后可以跑一遍校验：

```bash
node validate.js
```

## 技术

原生 HTML / CSS / JavaScript，无框架、无构建工具。站点数据在 `data.js`，页面逻辑在 `app.js` 和 `js/` 目录下，云同步接口在 `functions/`（Cloudflare Pages Functions）。
